# 申请交流图表材料

建议先打开 **申请交流图表初稿.pptx**。这是 7 页可修改初稿，含项目介绍和六张结果图；可以修改标题、中文结论与说明，补上个人信息。主线建议使用介绍页、图 01、03、06；图 02、04、05 作为机制讨论或备份页。图片中的数值标签为英文，便于用于中英文交流。

| 文件/目录 | 用法 |
| --- | --- |

## 展示口径

- 图 01 的每条灰线代表同一个模型 seed。Random 先在该模型 seed 内对五个 selection seeds 求均值，再与 TopK 配对；没有把 25 次 Random 当成 25 个独立模型 seed。
- 图 04、06 的误差线是标准差（SD），不是置信区间。图 04 各方法 SD 包含的随机性成分不同，不宜通过误差线重叠来判断显著性。图 02 只有描述性均值差。
- 图 01/02/04/05 属于早期候选池实验；图 06 是 4,000 候选池、重新执行训练的后期实验。两阶段的绝对分数不能拼成一次横向排名。
- 来源矩阵中 Real 训练量是 200，synthetic 训练量是 1,600；每个单元三个模型 seed。它适合说明域兼容性，不能用于等预算生成器排名。
- 以上是开发集或诊断结果，均不作为最终 holdout 结论，也没有新增统计显著性主张。

## 原表核对时发现的问题

`04_CaR筛选器对照.xlsx / Main_Comparison` 的 Original DSIR 行是 0 次运行且指标空白，LN-DSIR 行是 80 次汇总；这与独立 DSIR/LN 原表的 25 次记录不同。因此图 04 的 DSIR、LN-DSIR 与 Random/TopK 基线均取自独立 LN 工作簿，只从 CaR 总表取 RA-CaR。`06_原始DSIR对照.xlsx` 可再次核对原始 DSIR 的 25 次记录。此次整理保留原表副本，没有改写原实验结果。

## 修改与重新生成

仅调整 PPT 标题或说明，直接在 PowerPoint 中编辑。调整 Excel 图表样式，使用 `展示数据与可编辑图表.xlsx` 的原生图表；图 03 可编辑颜色刻度单元格。修改脚本后重新生成：

```bash
python -m pip install -r requirements-presentation.txt
python tools/build_research_presentation.py
```

脚本读取六个原始工作簿并重新生成展示文件。重跑会覆盖当前同名 PPT、展示工作簿、图和来源副本；手工编辑的版本应先另存。
