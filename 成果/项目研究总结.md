# 多来源合成文本的数据筛选与真实域泛化

展示材料见 [图表使用说明](图表使用说明.md)：已整理关键原始 Excel、可编辑图表工作簿、高清 PNG/SVG，以及七页申请交流 PPT 初稿。

## 项目简介

本项目围绕一个实际问题展开：**在训练样本预算固定时，如何从不同生成模型产生的文本中挑选更有助于真实数据泛化的样本？**

项目以 AG News 四分类为实验平台，使用 BERT 作为下游分类器，主要比较真实数据锚定的样本筛选、分布匹配、训练时加权、生成来源配比和模型 verifier 排序。研究过程中固定训练预算与评估协议，并逐步把评价重点从“合成数据内部能否取得高分”转向“所选数据是否提升对真实新闻的表现”。

## 主要成果

### 1. 在固定预算下验证真实数据锚定筛选的开发集信号

Real-Anchored TopK 按类别计算合成样本与真实参考样本的语义邻近度，再在来源与类别内固定预算选样。在 Dev2000 多 seed 验证中：

| 方法 | Accuracy | Macro-F1 |
| --- | ---: | ---: |
| 25 组随机选样的均值 | 72.59% ± 3.29% | 70.17% ± 4.46% |
| Real-Anchored TopK | **75.26% ± 3.16%** | **73.98% ± 4.05%** |
| 均值差 | **+2.67 个百分点** | **+3.81 个百分点** |

TopK 与随机方法按五个模型 seed 配对时，两项指标均为 5/5 个 seed 正向；在 25 组随机选样比较中，TopK 的 Accuracy 和 Macro-F1 胜率分别为 88% 和 96%。Sci/Tech 类的配对 Macro-F1 平均提升约 10.13 个百分点，其他类别增益较小。

这说明真实数据锚定的局部相关性在当前候选池与固定预算设置中具有明确的开发集信号。它仍是单一候选池上的探索性结果，需在独立候选池和冻结后的最终评估上确认。

### 2. 用来源兼容性矩阵量化 synthetic–real mismatch

项目构建 Real、Qwen、Llama、两种来源混合的 4×4 训练来源—测试来源矩阵。合成数据每类 500 条，拆为 400 条训练数据和 100 条 holdout；每个矩阵单元运行三个模型 seed，共 48 次训练。

合成训练数据在合成 holdout 上的准确率大多达到 97%–100%，而相同来源训练后在真实测试集上的准确率约为 68%–70%。例如，Qwen 训练在 Qwen 测试上为 99.83%，但在 Real 测试上为 68.00%；Llama 训练对应为 99.42% 和 70.33%。真实训练在真实测试上为 69.83%。

矩阵显示，synthetic-to-synthetic 高分并不能替代真实域泛化评估；训练与测试来源之间存在明显兼容性差异。由于每个单元只有三个 seed，这一矩阵适合做诊断，不直接支持普遍的来源优劣或最优配额结论。

该矩阵中 Real 训练使用 200 条样本，synthetic 训练使用 1,600 条；训练预算不同，也限制了跨来源性能差异的解释。它不是等预算的生成器排名。

### 3. 系统比较筛选器与机制假设，保留有解释力的负结果

- **训练时加权（DIMP）**：相较普通交叉熵，收益有限且 Qwen、Llama 的结果方向不一致；当前证据不支持它对不同生成器稳定有效。
- **分布距离（MMD）**：Real–Qwen 与 Real–Llama 的整体 MMD 均明显高于 Qwen–Llama，但距离度量不能直接代表下游效用，且早期重复抽样不确定性实现存在限制。
- **DSIR 与长度归一化 DSIR**：原始 DSIR 的有效样本量（ESS）中位数约为 1；长度归一化后提升到约 49.58，缓解了权重集中问题，但下游表现仍未超过 TopK。
- **聚类与自适应配额（CaR、ARA-TopK）**：方法改变了聚类覆盖或分布诊断，但未带来超过 TopK 的下游优势。ARA-TopK 的 Macro-F1 相对 TopK 低约 1.03 个百分点。
- **粗粒度来源配额与候选池扩容**：目前未观察到稳定的单调 quota response，也不支持“候选池越大越好”。小池实验还存在配额与池内筛选深度同时变化的混杂。

这些结果帮助收窄研究方向：改善权重、距离或多样性指标本身并不保证提升真实域效用，固定预算下的样本质量与来源兼容性需要直接对照真实评估。

### 4. 检验 verifier 排序的下游效用边界

在固定的 4,000 条候选池上，项目比较 Random、TopK、SelfVerifier 和 CrossVerifier。主比较共 40 次 BERT 训练；独立的 source-only 对照另作辅助分析。

| 方法 | Dev Accuracy | Dev Macro-F1 |
| --- | ---: | ---: |
| Random | 70.67% ± 4.99% | 68.21% ± 6.28% |
| Real-Anchored TopK | 74.62% ± 5.31% | **73.57% ± 6.07%** |
| SelfVerifier | 72.11% ± 2.51% | 70.90% ± 2.52% |
| CrossVerifier | 73.92% ± 2.95% | 72.92% ± 3.60% |

CrossVerifier 的 Macro-F1 比 SelfVerifier 平均高 2.02 个百分点，五个模型 seed 中四个正向；比 Random 的分层均值高 4.71 个百分点，五个 seed 均正向。但它仍比 TopK 低 0.65 个百分点，只有一个 seed 高于 TopK。按实验预先设定的解释规则，本轮 verifier 选择效用归类为 **No useful signal**：结果不足以支持以 verifier 替代 TopK，也不足以支持进一步堆叠 verifier 复杂度。

该实验也记录了 640 条历史候选的精确生成 checkpoint 未保存、只有一个候选池、以及固定方法缺少跨池重复等限制。结果适用于当前冻结候选池和协议，不应泛化为 verifier 方法整体无效。

## 方法与工程产出

- 建立固定训练预算、来源×类别分层选样、selection seed 与 model seed 配对的实验协议。
- 对候选集、运行结果、提示词和关键配置保存 manifest/hash，并为 verifier 下游实验独立复算预测指标与配对差值。
- 将数据加权、分布诊断、样本筛选、来源配比、候选池变化与 verifier 评估纳入同一条研究路线。
- 保留失败试验、负结果与口径限制，区分开发集、合成 holdout、历史协议和最终 holdout，避免把不同实验直接混排。

## 当前结论

当前最有力的经验结论是：**在本项目的 AG News 固定预算设置中，真实参考数据引导的局部语义筛选比随机选样更有开发集效用；但更复杂的分布匹配、聚类或 verifier 方案尚未稳定超过该基线。** 来源兼容性矩阵同时说明，只看合成 holdout 容易高估合成训练数据的真实泛化能力。

因此下一步应优先在独立候选池上复现 TopK 与 verifier 对照，再设计小幅来源配额扰动，估计 source×class 的边际效用；方法冻结前继续保留 Final Holdout。

## 与教授交流时的简短介绍

我研究的是固定训练预算下合成数据的筛选问题。最初从训练时质量加权入手，但 DIMP 的收益在不同生成器之间并不稳定，因此我把问题转向“同样数量的数据里哪些样本真正有助于真实数据泛化”。在 AG News 四分类实验中，真实数据锚定的 TopK 在 Dev2000 上比随机选样高约 2.7 个百分点 Accuracy、3.8 个百分点 Macro-F1；来源兼容性矩阵也显示，合成 holdout 的近满分与真实测试上的约 68%–70% 之间存在明显落差。后续 verifier 对照没有超过 TopK，这让我更关注真实域效用、候选池外验证和来源×类别的边际贡献，而不是继续堆复杂筛选器。
